# Beenish Kashif — Task 3: Multipage CV Website

This project is based on the supplied Task 1 portfolio ZIP and uses the same CV details, projects, training, certificate, resume PDF, and teal/amber theme.

## Pages
- `index.html` — Home / CV overview
- `about.html` — Profile and career interests
- `skills.html` — Technical skills
- `projects.html` — Three selected projects
- `education.html` — Academic record
- `training.html` — Training, certificate, and recognition
- `contact.html` — Email, LinkedIn, and GitHub

## Run locally
Extract the ZIP and open `index.html` in a browser. No build step or package installation is required. External links and certificate verification require an internet connection.

## Structure
- HTML pages at the project root
- `style.css` shared responsive styling
- `script.js` mobile navigation and footer year
- `Beenish_BSCS_Resume.pdf` downloadable CV
- `google-coursera-certificate.png` certificate image
- `favicon.svg` site icon
